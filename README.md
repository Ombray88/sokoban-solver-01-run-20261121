A push-optimal Sokoban solver: it decomposes each level into its rooms, solves every room with a push-optimal search (A* over pushes with a Hungarian assignment heuristic and deadlock pruning), then stitches the rooms together into one move sequence.

## Run it

```bash
MAKEFUN_INPUT_DIR=<input dir> MAKEFUN_OUTPUT_DIR=<output dir> node main.ts
```
